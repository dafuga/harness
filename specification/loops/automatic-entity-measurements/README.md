# Automatic entity measurements

Source metrics were displayed only from full verification records, performance rows only from budget declarations, and focused proofs discarded benchmark captures. The previous verdict test also required a red cross for missing evidence.

The existing history-index, loop, entity-measure, verdict and responsive entity-preview suites now cover these missing states. Source size and complexity are computed from each selected Git tree. Benchmark observations are preserved in immutable focused records and displayed without granting full verification or budget approval. Callable metadata keeps sibling helpers apart. Standard casing tests automatically benchmark all four transforms when verification requests evidence, after checking independent expected returns.

The casing workload is `Hello world`: three warmups and the median of five batches of 1,000 calls. Memory is the benchmark process peak RSS, including the test runner, not an attribution to one helper. A module without a standalone artifact is explicitly not applicable. Missing verification is neutral; actual failed checks remain red.

Test-only commits precede the repair. The final red and green records, exact inputs, command, profile and measurements are retained in Harness Git evidence and linked on the entity History page. Focused results do not claim complete repository verification.

Validation: 602 web unit tests, ten core history/loop integration tests, nine additional measurement/record tests, and desktop/tablet/mobile browser checks passed. The web package check, root formatting/types/lint and registry validation passed. The root audit still finds the existing 221-line `test/utils/explorer-route.test.ts`; full repository verification remains pending. Electron was not launched or tested.

The live multi-metric screenshot exposed a second coverage gap: the responsive fixture had only one short metric. The same standard fixture now includes timing, process RSS, a full profile id and long method notes, and asserts that metric words stay whole at every supported width. The summary gives multiple metrics a full row and separates notes from values. Missing E2E evidence uses a neutral border as well as a neutral icon.
