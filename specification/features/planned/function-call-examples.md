# Feature: Function Call Examples

## Overview

Show the simplest possible function usage: a short title, a call with example parameters, and its expected output in a code comment.

## Acceptance Criteria

- Each example contains only a short title and one escaped code block.
- Code includes example parameters and an expected output comment directly below the call; expected errors use a throws comment.
- No table, numbered labels, descriptions, comparison panels, raw documents, shared-setup disclosure, or verification disclosure appears in Examples.
- Legacy setup, when needed, remains inside the code block. Missing authored calls are stated in comments rather than invented.
- Desktop, tablet, and mobile retain revision-specific documentation without horizontal page overflow.
- Activity freshness examples are self-contained calls executed by automated tests against the real function. The browser displays code without executing it.
