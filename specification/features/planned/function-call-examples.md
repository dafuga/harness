# Feature: Function Call Examples

## Overview

Show how a function is called and how its expected result changes across examples.

## Acceptance Criteria

- Each documented call is shown as escaped code beside compact expected output or error.
- Later examples show the changed output relative to the first example, preserving null, false, zero, empty values, and expected errors.
- Shared setup can be read without repeating it in every call. Missing authored calls are stated, never invented.
- Desktop, tablet, and mobile retain revision-specific documentation and do not overflow.
- Activity freshness calls execute in isolated test contexts and return the documented projected results. Browser views display code without executing it.

## Future Enhancements

- Interactive execution is outside this change.
