# Feature: Compact revision controls

Branch and commit selectors share one compact row inspired by GitHub repository controls. Keep the full native options, values, keyboard navigation and branch/commit URLs.

- Closed controls are 32px high with bounded widths; the row stays under 48px and 380px wide on desktop, tablet and phone. Coarse-pointer targets may grow to 44px.
- Long selected names show their first and last six characters, separated by an ellipsis. Full values and revision status are available on hover and to assistive technology.
- Inline icons replace separate label and status rows. Go to tip is one small icon with its accessible name preserved.
- Other Select consumers and comparison controls keep their current layout.

Existing standardized shell and workspace coverage checked visibility and navigation but allowed expanding revision controls and end-only truncation. Extend those cases with compact geometry and long-name assertions before repair.
