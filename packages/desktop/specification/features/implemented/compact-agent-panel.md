# Feature: Compact Agent Panel

## Overview

The Work with agent panel gives writing more room by consolidating its lower controls.

## Acceptance Criteria

- At desktop and 390px widths, controls below the message take at most 115px.
- Model, effort, provider and visual design count remain usable with their accessible labels.
- Sending still carries the selected settings; Change still requires approval.
- Other composer contexts keep their existing behavior and the panel fits the viewport.

## Future Enhancements

- None in this change.
