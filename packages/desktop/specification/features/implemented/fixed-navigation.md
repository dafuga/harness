# Feature: Fixed Navigation

## Overview

The shared app navigation remains at the viewport top while the catalog scrolls.

## Acceptance Criteria

- At desktop, tablet and phone widths, scrolling leaves the navigation at viewport y=0.
- Responsive navigation height remains in document flow so initial content is not hidden.
- Navigation links remain usable after scrolling and the existing shared navigation is reused.

## Future Enhancements

- None in this repair.
