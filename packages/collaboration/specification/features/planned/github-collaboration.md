# Private GitHub collaboration

Human comments never execute agents. Private GitHub records authorize each operation afresh; non-force branch compare-and-swap retries reload membership. Invitation codes are hashed, expire, bind verified email/project/action, and are consumed once. Source reads bind exact repository/ref/commit/tree; LFS bytes are verified. Disposable caches partition principal, project, repository, source, notes, evidence, history, artifact and profile. Tests use synthetic GitHub HTTP responses; no real provider mutation is authorized.

Raw source bytes remain independently Git-attested before LFS materialization. Entity history uses bounded path-filtered pages at exact commits, deduplicates overlapping owned paths, and reports provider pagination without walking every ancestor tree.
